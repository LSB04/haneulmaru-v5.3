하늘마루 V5.4 — 양재 / 아크 강남 지도 출처

기준 주소: 사용자가 제공한 서울 서초구 강남대로30길 7.
네이버 지도에서 아크 강남 장소명과 동일 주소를 확인함.
https://map.naver.com/p/entry/place/2074997258
구글 지도 검색도 수행했으나 정확한 주소 대신 주변 검색 결과가 나와
장소 확인에는 네이버 지도를 사용함. 네이버/구글 지도 이미지나 3D 타일은 포함하지 않음.

주소 기준점: 위도 37.4819231 / 경도 127.0375193.
https://en.findby.co.kr/details/06743-116504163015-st-696522b997caf6cbe6ba9607
좌표는 주소 서비스의 위치이며 건물 경계 실측이나 GPS 측량 결과가 아님.

도로·건물 윤곽·공원·하천: © OpenStreetMap contributors.
원본: data/yangjae-osm.json (OSM API 스냅샷, 2026-10-11 수집).
https://api.openstreetmap.org/api/0.6/map?bbox=127.0306,37.4764,127.0444,37.4874
파생 데이터: city-data.js. 약 1.2 km 사각 범위로 건물과 토지를 절단.
도로는 렌더링 단계에서 같은 범위로 절단. 원본 way의 공개 태그에서
건물 427개, 도로/하천 way 344개, 공원/수면 등 19개를 선택.

데이터 재배포 시 출처와 동일 라이선스를 유지해야 함.
코드와 직접 제작한 드론 형상은 OSM 지리 데이터와 구분됨.

정확도 / 추정 범위
- 건물 188개는 OSM 높이 또는 층수 태그 기반. 층수만 있으면 층당 3.3m로 환산.
- 건물 239개는 높이 정보가 없어 12~35.1m의 결정적 추정값 사용.
- OSM의 기존 건물/도로 정보도 현재 현장과 다를 수 있음.
- 건물 외벽 색·창문·옥상 설비·나무 배치는 시각적 표현이며 실측 외관이 아님.
- 지면은 y=14의 가상 평면. DEM, 위성 정사영상, 실제 고도 데이터는 사용하지 않음.
- 대회장은 주소 기준점의 링/라벨로 표시. 해당 건물의 정확한 외곽·높이를
  확인하지 못했으므로 임의 건물을 실제 대회장 건물이라고 표시하지 않음.
- x=동쪽, z=남쪽, y=위쪽. 근거리 평면 근사이며 정밀 측량용이 아님.
- 드론은 직접 만든 3종의 합성 모델이며 실제 기체 크기와 성능을 뜻하지 않음.

지도·모델은 로컬 파일로 로드되며 실행 중 외부 지도 API/타일 요청이 없음.
