V5.4 영상 멈춤 수정 - 2026-10-11

코드에서 확인한 복구 누락
- 프레임 캡처가 2초 내 완료되지 않으면 active=false로 고정되어 이후 렌더링이 재개되어도 영상이 돌아오지 않음.
- 송신기와 수신기의 영상 소켓 종료 후 자동 재연결 없음.
- 디코더 설정의 epoch 불일치 시 키프레임만 요청하고 설정 정보는 재전송하지 않음.
- WebGL 컨텍스트 상실 후 복구 이벤트에서 렌더 루프를 재개하지 않음.
이 항목들은 코드에서 확인한 결함이며, 사용자의 실제 휴대폰에서 어느 항목이 직접 발생했는지는 현장 로그로 확정하지 않음.

수정
- 일시적인 캡처 실패 후 1초 간격으로 재시도하고 키프레임부터 전송.
- 양쪽 영상/조작 소켓 재연결 및 이전 연결 콜백 무효화.
- 갱신이 2.5초 이상 멈추면 디코더와 키프레임 재동기화, 8초 이상이면 재연결.
- 키프레임 요청에 코덱 설정 재전송. 동일 설정은 정상 디코더를 초기화하지 않음.
- 매 프레임의 불필요한 수신 캔버스 크기 재설정 제거.
- GPU 컨텍스트 복구 후 렌더 루프 재개.
- Windows GPU 선호도 설정 실패 시 기존 설정으로 실행을 계속함.

검증
- JavaScript 자동 테스트 71개 통과(복구 회귀 테스트 4개 포함).
- 실행한 PC 렌더러에서 로컬 TLS 인증, 시점 전환 응답 확인.
- 동일 PC의 수신 시험에서 10초 동안 H.264 패킷 600개, 키프레임 10개 수신.
- 이는 휴대폰 무선 디코딩 FPS 측정이 아님. 실제 Android 앱에서 재확인 필요.
- nvidia-smi는 권한 문제로 GPU 사용률을 확인하지 못했음.

적용
수정은 PC가 제공하는 웹 코드이므로 이 변경만을 위해 APK를 다시 설치할 필요는 없음.
PC 지형 창은 화면에 띄워두고, 앱을 다시 열어 PC의 최신 QR 주소로 로컬 연결 후 PC 연결 시작을 누를 것.
서버를 다시 실행하면 연결키가 달라질 수 있으므로 이전 QR 주소는 사용하지 않음.
앱의 다른 기기 연결이나 의도적인 종료에서는 자동 재연결을 중단함.
