자동/실행 검증
- JavaScript 41개 테스트 통과 (도시 데이터·비행 여유 높이·줌·터치·합성 게임 포함).
- Python 22개 테스트 통과 (LAN 인증·전송·센서·설정 검증 포함).
- V5.3와 V5.4 APK SHA-256 동일, 로컬 CA 인증서 SHA-256 동일.
- TLS 인증서 검증 활성 상태로 V5.4 HTTPS 및 영상/조작 WSS 연결 성공.
- 로컬 서브넷 범위 Windows 방화벽 규칙 적용 확인.
- 실제 서버/렌더러에서 줌·시점 변경·색상 생성·파랑 20개 제한 동작 확인.
- RTX 2080 Ti / D3D11, 소프트웨어 렌더링 아님.
- 고화질 2560x1468 렌더링 관측 약 60 FPS, p95 프레임 16.8 ms.
- fast 프로필 동일 PC LAN TLS 테스트: H.264 10초간 600개 패킷/60 FPS,
  키프레임 10개. NVIDIA 인코더 사용률 관측 최고 13%.

제한
- 위 영상 수신 수치는 같은 PC의 테스트 수신부 값이며 실제 휴대폰 무선 측정이 아님.
- 이번 검증 중 외부 인터넷을 물리적으로 끄지는 않음. 지도·모델 파일은 로컬 포함.
- V5.3 앱의 실제 휴대폰 재접속·USB 센서 실물 입력은 사용자 기기에서 확인 필요.
- CLIKA 모델 및 게임 로직은 기존 구성 유지. 새 모델 학습/최적화 검증은 수행하지 않음.
- OSM에 없는 건물은 비어 있음. 지면은 평면이며 정밀 DEM/실측 3D 스캔이 아님.
